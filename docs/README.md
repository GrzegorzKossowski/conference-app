## Jak używać — Organizator

Wejdź na /organizer/login, zaloguj się: organizer@example.com / XoR4cPjPcYaE
/organizer — lista wydarzeń, przycisk "+ Nowe wydarzenie"
Utwórz wydarzenie: tytuł, opis, lokalizacja, data, limit miejsc. Slug do URL generuje się automatycznie z tytułu.
Wejdź w szczegóły wydarzenia — widzisz statystyki (ile osób zapisanych/potwierdzonych/obecnych) i listę Gości.
Kliknij "Skanuj bilety" → przycisk [SKANUJ] → kamera telefonu skanuje QR gościa → kolorowy banner pokazuje status (zielony = obecny, żółty = już zarejestrowany, czerwony = nieprawidłowy/nieaktualny bilet).

## Jak używać — User (uczestnik)

Wchodzi na /event/[slug-wydarzenia] (link dostajesz z panelu organizatora, przy tytule eventu)
Wypełnia formularz: email, opcjonalnie imię/nazwisko → "Zapisz się"
Od razu ląduje na stronie z biletem — kod QR + swój unikalny kod dostępu (np. H7MMTR33)
Może wrócić później na /ticket, wpisać swój kod i zobaczyć bilet ponownie (bez logowania hasłem — kod pełni tę rolę)
